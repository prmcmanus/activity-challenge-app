Build the Active Together shortcut

For whoever sets up the shared Apple Shortcut for everyone else. If someone has already shared it, you don't need this: see Sync from your phone.

It takes about 20 minutes, and only one person needs to do it. In Shortcuts, tap + at the top right, tap the name at the top and call it exactly Active Together sync. Find each action below with the search bar at the bottom ("Search for apps and actions"). Where it says to choose a variable, tap the field and pick it from the suggestions above the keyboard, or use Select Variable.

Let it receive the key: tap the ⓘ (or the name at the top, then Details) and turn on Show in Share Sheet. A line appears at the top, "Receive Any input from Share Sheet": tap Any and choose only Text, and set If there's no input to Continue.

Part 1: remember the key (actions 1 to 10)

  1. If: Shortcut Input has any value.
  2. Save File (inside the If): save Shortcut Input; turn Ask Where to Save off; set the path to ActiveTogether-key.txt and turn on Overwrite If File Exists.
  3. Move the Otherwise line so it sits after Save File (it's already there if you added If first).
  4. Get File from Folder (inside Otherwise): folder Shortcuts, path ActiveTogether-key.txt, Error If Not Found off.
  5. If: File does not have any value.
  6. Ask for Input: type Text, prompt Paste your Active Together sync key.
  7. Save File: save Provided Input, same settings as action 2.
  8. Check the order: End If (inner), then End If (outer).
  9. After both End Ifs, Get File from Folder again: folder Shortcuts, path ActiveTogether-key.txt.
  10. Get Text from Input (the file), then Set Variable: name it Key.

Your answers (asked once, then remembered on the iPhone, so one shortcut suits everyone)

  1. Get File from Folder: folder Shortcuts, path ActiveTogether-watch.txt, Error If Not Found off.
  2. If: File does not have any value.
  3. Choose from Menu (inside the If): prompt Do you wear an Apple Watch?, options Yes and No.
  4. Under Yes: a Text action with yes. Under No: a Text action with no.
  5. After End Menu, still inside the If: Save File, saving the Menu Result; Ask Where to Save off, path ActiveTogether-watch.txt, Overwrite If File Exists on.
  6. After End If: Get File from Folder again (same path), then Get Text from Input, then Set Variable: name it Watch.
  7. Repeat a–f for cycling: path ActiveTogether-cycle.txt, prompt Do you cycle?, and name the variable Cycle.

The first run asks both questions (that's the run Connect this iPhone starts); after that the answers are read from the files, so the automations never ask. To change an answer, delete the file in the Files app (iCloud Drive › Shortcuts) and run the shortcut once.

Part 2: steps (actions 11 to 17)

  1. Find Health Samples: Type Steps. Tap Add Filter and set Start Date is in the last 2 days. Tap Show More: Group By Day.
  2. Repeat with Each (item in Health Samples). Put the next four actions inside it, above End Repeat.
  3. Get Details of Health Sample: Start Date of Repeat Item.
  4. Format Date: Date Format Custom, format yyyy-MM-dd.
  5. Get Details of Health Sample: Value of Repeat Item.
  6. Get Contents of URL: URL https://activetogether.team/api/shortcut/day. Tap Show More: Method POST; Request Body JSON → Add new field → Text: key key, value the Key variable; then Text: key date, value Formatted Date; then Number: key steps, value Value (from action 15). (Don't put the key in a header: an invisible line break at its end makes Cloudflare reject the request with "400 Bad Request".)
  7. Check that End Repeat comes after action 16.

Part 3: walking and running distance: duplicate actions 11 to 17 (long-press each, Duplicate, and drag the copies below End Repeat). Set the type to Walking + Running Distance, call the number field distance, add one more Get Details of Health Sample inside the repeat to get the Unit of Repeat Item, and add a Text field distance_unit whose value is that Unit.

Part 4: exercise minutes (Apple Watch only): duplicate actions 11 to 17 (long-press each, Duplicate, and drag the copies below End Repeat). In the copy, set the type to Exercise Minutes, rename the field steps to minutes, and make sure Repeat Item, Formatted Date and Value point at actions in the copy, not the original. Then wrap the whole part in an If: add If above its Find Health Samples with Watch is yes, delete the Otherwise line, and drag End If below its End Repeat. An iPhone on its own records no exercise minutes, so without the If this part would stop the shortcut for everyone else.

Part 5: cycling distance (keep this last): duplicate the distance part once more. Set the type to Cycling Distance, call the number field cycling_distance and the unit field cycling_unit. Cycling is sent separately so it only counts where rides do: in cycling journeys, and in ordinary distance challenges (walking and cycling added together). On-foot journeys only take walking and running. Change its Find Health Samples filter to is in the last 30 days (people don't ride every day, and sending a day again just updates it), and wrap the part in an If with Cycle is yes, the same way as Part 4.

Why the questions and the order matter. When Find Health Samples finds nothing it stops the whole shortcut with "No Samples Found", so every part after it is skipped. Steps and distance always have data on an iPhone, so they come first; exercise minutes and cycling only run for people who said yes, with cycling last, since many days have no ride.

Tap Done. Then connect it: on the website on that iPhone, tap Set up under "Sync from your phone", then Connect this iPhone.

If your steps look a little higher than in the Health app, check that each Find Health Samples has Group By: Day. That makes Apple Health count an Apple Watch and an iPhone together only once.

Share it

Your key and your answers aren't inside the shortcut (they're in files on your iPhone), so it's safe to share as it is. Tap the ⌄ next to its name → Share → Copy iCloud Link, and give the link to the site's administrator to put behind Get the shortcut on the website (or send it round). Each person is asked the two questions on their first run.
