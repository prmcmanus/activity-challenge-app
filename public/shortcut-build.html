Build the Active Together shortcut

For whoever sets up the shared Apple Shortcut for everyone else. If someone has already shared it, you don't need this: see Sync from your phone.

It takes about 20 minutes, and only one person needs to do it. In Shortcuts, tap + at the top right, tap the name at the top and call it exactly Active Together sync. Find each action below with the search bar at the bottom ("Search for apps and actions"). Where it says to choose a variable, tap the field and pick it from the suggestions above the keyboard, or use Select Variable.

Part 1: your key (action 1)

  1. Text: paste your sync key (on the website: Set up under "Sync from your phone", then Show my sync key, Copy).

Part 2: steps (actions 2 to 8)

  1. Find Health Samples: Type Steps. Tap Add Filter and set Start Date is in the last 2 days. Tap Show More: Group By Day.
  2. Repeat with Each (item in Health Samples). Put the next four actions inside it, above End Repeat.
  3. Get Details of Health Sample: Start Date of Repeat Item.
  4. Format Date: Date Format Custom, format yyyy-MM-dd.
  5. Get Details of Health Sample: Value of Repeat Item.
  6. Get Contents of URL: URL https://activetogether.team/api/shortcut/day. Tap Show More: Method POST; Request Body JSON → Add new field → Text: key key, value the Text from action 1; then Text: key date, value Formatted Date; then Number: key steps, value Value (from action 6). (Don't put the key in a header: an invisible line break at its end makes Cloudflare reject the request with "400 Bad Request".)
  7. Check that End Repeat comes after action 7.

Part 3: exercise minutes: duplicate actions 2 to 8 (long-press each, Duplicate, and drag the copies below End Repeat). In the copy, set the type to Exercise Minutes, rename the field steps to minutes, and make sure Repeat Item, Formatted Date and Value point at actions in the copy, not the original.

Part 4: distance: duplicate actions 2 to 8 again. Set the type to Walking + Running Distance, call the number field distance, add one more Get Details of Health Sample inside the repeat to get the Unit of Repeat Item, and add a Text field distance_unit whose value is that Unit.

Part 5: cycling distance: duplicate the distance part once more. Set the type to Cycling Distance, call the number field cycling_distance and the unit field cycling_unit. Cycling is sent separately so it only counts where rides do: in cycling journeys, and in ordinary distance challenges (walking and cycling added together). On-foot journeys only take walking and running.

Tap Done, then tap the shortcut to run it once. Allow access to Health and to activetogether.team when asked, and check My activity on the website.

If your steps look a little higher than in the Health app, check that each Find Health Samples has Group By: Day. That makes Apple Health count an Apple Watch and an iPhone together only once.

Share it

So that everyone else just adds it and pastes their own key:

  1. Tap the ⌄ next to the shortcut's name, then the ⓘ, then Setup. Under Import Questions, add one for the Text action (action 1) and call it Paste your Active Together sync key.
  2. Delete your own key from the Text action, so it isn't shared.
  3. Share → Copy iCloud Link, and give the link to the site's administrator to put behind Get the shortcut on the website (or send it round).
