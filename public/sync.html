Sync your activity automatically

You can always log activity by hand on the website. To have it counted for you, connect your phone. Your watch or fitness band doesn't need its own connection: its app passes everything to your phone's health store (Health Connect on Android, Apple Health on iPhone), and Active Together picks it up from there.

Use one way per challenge. If two of these send the same activity (say, the app and the shortcut), it counts twice. Pick one, or delete the duplicates under My activity.

Android: the Active Together app

  1. Sign in on this website, and on the home page tap Download for Android. Open the downloaded file to install it (allow installs from your browser if Android asks).
  2. Open the app, sign in, go to Sync and allow access to Health Connect when asked.
  3. Review your workouts and upload them, or turn on Sync automatically under Me.

With a Fitbit

In the Fitbit app (now called Google Health on some phones): tap your profile picture, then Health Connect, and turn sharing on for steps, exercise and distance.

With a Garmin (Android 14 or newer)

In Garmin Connect: More (or your profile) → Settings → Health Connect, and allow it to write steps, activities and distance.

With a Samsung, Pixel Watch or other app

Most fitness apps have a Health Connect option in their settings. Turn on writing exercise, steps and distance.

iPhone: Apple Shortcuts

Shortcuts is a free app from Apple, already on your iPhone (search for "Shortcuts" if you can't see it). Once set up, it sends your day's steps, exercise minutes, walking and running distance and cycling distance from Apple Health twice a day, so it counts in step, minutes and distance challenges and in virtual journeys alike. It sends daily totals, not individual workouts.

Works with an Apple Watch, an iPhone on its own, or a Garmin. In Garmin Connect, go to More → Settings → Connected Apps → Apple Health and switch sharing on.

Set it up (about two minutes)

  1. On your iPhone, open activetogether.team in Safari, sign in, and tap Set up Apple Shortcuts on the home page.
  2. Tap Get the shortcut, then Add Shortcut. Keep its name, "Active Together sync".
  3. Go back to the website and tap Connect this iPhone. Shortcuts opens and runs it once. Allow it to read Steps, Exercise Minutes, Walking + Running Distance and Cycling Distance, and choose Always Allow when it asks to connect to activetogether.team or to save a file.
  4. Check My activity on the website: you'll see entries marked "shortcut" for yesterday and today.
  5. Make it automatic, below.

If Get the shortcut isn't there yet, build the shortcut yourself first.

Make it automatic

  1. In Shortcuts, tap Automation at the bottom, then + (or New Automation).
  2. Choose Time of Day, pick 21:00 and Daily, and choose Run Immediately (turn off Notify When Run if you like). Tap Next and choose Active Together sync.
  3. Add a second automation the same way for 08:00. The morning run finishes off yesterday's totals.

iPhone keeps Health data locked while the phone is locked, so a run while it's locked sends nothing. That's harmless: every run sends both yesterday and today, and sending a day twice just updates it.

Build the shortcut yourself

Only needed if nobody has shared it yet. It takes about 20 minutes. In Shortcuts, tap + at the top right, tap the name at the top and call it exactly Active Together sync. Find each action below with the search bar at the bottom ("Search for apps and actions"). Where it says to choose a variable, tap the field and pick it from the suggestions above the keyboard, or use Select Variable.

Let it receive the key: tap the ⓘ (or the name at the top, then Details) and turn on Show in Share Sheet. A line appears at the top, "Receive Any input from Share Sheet": tap Any and choose only Text, and set If there's no input to Continue.

Part 1: remember the key (actions 1 to 10)

  1. If: Shortcut Input has any value.
  2. Save File (inside the If): save Shortcut Input; turn Ask Where to Save off; set the path to ActiveTogether-key.txt and turn on Overwrite If File Exists.
  3. Move the Otherwise line so it sits after Save File (it's already there if you added If first).
  4. Get File from Folder (inside Otherwise): folder Shortcuts, path ActiveTogether-key.txt, Error If Not Found off.
  5. If: File does not have any value.
  6. Ask for Input: type Text, prompt Paste your Active Together sync key.
  7. Save File: save Provided Input, same settings as action 2.
  8. Check the order: End If (inner), then End If (outer).
  9. After both End Ifs, Get File from Folder again: folder Shortcuts, path ActiveTogether-key.txt.
  10. Get Text from Input (the file), then Set Variable: name it Key.

Part 2: steps (actions 11 to 17)

  1. Find Health Samples: Type Steps. Tap Add Filter and set Start Date is in the last 2 days. Tap Show More: Group By Day.
  2. Repeat with Each (item in Health Samples). Put the next four actions inside it, above End Repeat.
  3. Get Details of Health Sample: Start Date of Repeat Item.
  4. Format Date: Date Format Custom, format yyyy-MM-dd.
  5. Get Details of Health Sample: Value of Repeat Item.
  6. Get Contents of URL: URL https://activetogether.team/api/shortcut/day. Tap Show More: Method POST; Headers → Add new header: key X-Sync-Key, value the Key variable; Request Body JSON → Add new field → Text: key date, value Formatted Date; then Number: key steps, value Value (from action 15).
  7. Check that End Repeat comes after action 16.

Part 3: exercise minutes: duplicate actions 11 to 17 (long-press each, Duplicate, and drag the copies below End Repeat). In the copy, set the type to Exercise Minutes, rename the field steps to minutes, and make sure Repeat Item, Formatted Date and Value point at actions in the copy, not the original.

Part 4: distance: duplicate actions 11 to 17 again. Set the type to Walking + Running Distance, call the number field distance, add one more Get Details of Health Sample inside the repeat to get the Unit of Repeat Item, and add a Text field distance_unit whose value is that Unit.

Part 5: cycling distance: duplicate the distance part once more. Set the type to Cycling Distance, call the number field cycling_distance and the unit field cycling_unit. Cycling is sent separately so it only counts where rides do: in cycling journeys, and in ordinary distance challenges (walking and cycling added together). On-foot journeys only take walking and running.

Tap Done, then connect it as in step 3 of Set it up.

If your steps look a little higher than in the Health app, check that each Find Health Samples has Group By: Day. That makes Apple Health count an Apple Watch and an iPhone together only once.

Share it with your challenge

Your key isn't inside the shortcut (it's in a file on your iPhone), so the shortcut is safe to share as it is. Tap the ⌄ next to its name → Share → Copy iCloud Link, and send the link round, or give it to the site's administrator to put behind Get the shortcut.

iPhone: the Active Together app

The iPhone app syncs individual workouts (with their type, times and, if you choose, the route) as well as steps. It isn't in the App Store yet, so it's installed from a computer with the free tool Sideloadly. With a free Apple Account the installed app has to be refreshed every 7 days, which Sideloadly can do automatically. See Get the iPhone app on the home page.

Stopping

  • Android: turn off Sync automatically under Me, or uninstall the app.
  • Shortcuts: delete the automations (and the shortcut), or remove your sync key on the website so it can't send anything.

Anything already synced stays in your challenges until you delete it under My activity.
